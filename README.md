### 🚀 [SpringSight AI](https://github.com/aldehydeketone/SpringSight-AI)

An AI-powered production log analyzer, purpose-built for Spring Boot developers — not a generic log viewer.

- **Parses** raw Spring Boot logs and classifies real framework failures — `BeanCreationException`, Hibernate/JPA errors, JWT & security misconfigurations
- **Diagnoses** root causes using a rule-based engine *first*, calling **Gemini AI** only when deterministic detection isn't enough (deliberate, not wasteful AI usage)
- **Secures** access with Spring Security + JWT, backed by MySQL and a React dashboard
